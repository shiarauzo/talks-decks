# Microinteracciones y movimiento

Charla de 60 minutos con demos en vivo: buenas vs malas microinteracciones,
basics de movimiento, y patrones útiles.

## Run

```bash
bun install
bun run dev
```

Abre http://localhost:3210

## Controles

| Tecla | Acción |
| --- | --- |
| → · Espacio · clic | Siguiente slide |
| ← | Anterior |
| N | Notas del speaker |
| F | Fullscreen |
| Home / End | Primero / último |

## Archivos

- `index.html` — slides + demos
- `styles.css` — look y motion
- `presentation.ts` — navegación
- `PRESENTATION-GUIDE.md` — guion con tiempos
